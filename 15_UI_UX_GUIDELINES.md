- Architect
- Developer
- QA
- System Integrator

- Keeps console and overlay experience coherent
- Defines interface boundaries

- Supports repeated operational use

## Design Principles

- Single Responsibility
- Composition over Duplication
- Event First
- Configuration First
- One URL
- Platform First
- Renderer Last

## Quality Expectations

- Low cognitive load for operators
- Clear status and recovery visibility
- Consistent visual language
- Accessible operational controls

## Rules

- Interfaces must support fast operator comprehension
- Status must be visible where decisions are made
- Visual consistency must not override architecture boundaries

## Extension Rules

- New interface patterns require documented purpose and workflow ownership
- User experience changes must preserve reliability and clarity

## Stability Rules

- UI and UX principles remain valid across interface technology changes
